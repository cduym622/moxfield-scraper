# moxfield-scraper
This program attempts to scrape decklists off of the public moxfield and archidekt decklists found at: 
https://api.moxfield.com/v2/decks/all/
  
This project then saves that scraped data into organized json files that can be used to train machine learning models on that data.

This project implements code from this repo regarding how to scrape and access moxfield and archideckt, and will be credited where code was taken:
https://github.com/thebear132/MTG-To-XMage/tree/main
